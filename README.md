Responsive Business Website

A modern, clean and fully responsive business website built for small businesses, startups and entrepreneurs.

🌐 Live Demo

✨ Features

- Responsive design for mobile, tablet and desktop
- Modern and clean user interface
- Mobile navigation menu
- Hero section with call-to-action buttons
- About section

- HTML5
- CSS3
- JavaScript

📱 Responsive Design

The website is designed to work smoothly across different screen sizes, including smartphones, tablets and desktop computers.

- "script.js" — JavaScript functionality
